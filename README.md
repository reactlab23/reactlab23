# ReactLab23 Communication Interface

🚀 **Система коммуникации для автоматизации и обработки данных**

## Описание

Этот проект добавляет функциональность коммуникации к существующим данным автоматизации (Blueprint) и TikTok. Система позволяет взаимодействовать с данными через веб-интерфейс и API.

## Возможности

### 💬 Real-time Chat (WebSocket)
- Мгновенное общение через WebSocket соединение
- Поддержка русского языка
- Автоматические ответы на простые запросы

### 📡 API Endpoints
- `GET /api/status` - Проверка статуса системы
- `GET /api/blueprint/info` - Информация о Blueprint данных
- `GET /api/tiktok/stats` - Статистика TikTok данных
- `POST /api/message` - Отправка сообщений через API

### 🎯 Поддерживаемые команды
- **статус/status** - Проверка работы системы
- **данные/data** - Информация о загруженных данных
- **привет/hello** - Приветствие

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск сервера
npm start
```

Сервер будет доступен по адресу: http://localhost:3000

## Технологии

- **Node.js** - Серверная платформа
- **Express.js** - Веб-фреймворк
- **WebSocket** - Real-time коммуникация
- **HTML/CSS/JavaScript** - Фронтенд интерфейс

## Использование

1. Откройте http://localhost:3000 в браузере
2. Используйте чат для общения в реальном времени
3. Тестируйте API через кнопки в интерфейсе
4. Просматривайте статистику и информацию о данных

## API Примеры

### Проверка статуса
```bash
curl http://localhost:3000/api/status
```

### Отправка сообщения
```bash
curl -X POST -H "Content-Type: application/json" \
  -d '{"message":"Привет!","type":"greeting"}' \
  http://localhost:3000/api/message
```
